# AWS Learning

A structured collection of hands-on AWS projects, labs, and infrastructure-as-code implementations. This repository serves both as a personal learning journal and a portfolio demonstrating practical experience with AWS services and cloud engineering concepts.

---

## About This Repository

This repository documents my journey through AWS cloud infrastructure and engineering. Each project is built hands-on, working through real configurations, debugging real errors, and making deliberate decisions — all documented along the way.

The goal is not just to follow instructions, but to understand the reasoning behind each architectural choice, develop problem-solving skills in a cloud environment, and build a solid foundation for working professionally with AWS.

---

## What I Am Learning

The focus of this repository covers a broad range of AWS and cloud engineering topics, including:

- **Infrastructure as Code** using Terraform and AWS CloudFormation
- **Networking** with VPCs, subnets, route tables, internet gateways, and security groups
- **Compute** with Amazon EC2, instance types, AMIs, and launch configurations
- **Storage** with Amazon S3 and related services
- **Serverless** with AWS Lambda and event-driven architectures
- **Security** with IAM roles, policies, and least-privilege principles
- **Monitoring** with Amazon CloudWatch

This list grows as new topics are explored and new projects are added.
