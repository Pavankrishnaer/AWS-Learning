Demo Project — Educational Use Only

ELLORE is an academic capstone project. Form submissions can be sent to AWS backend services for demonstration workflows such as contact handling, newsletter signup, and order simulation. Please do not enter sensitive real payment data. This privacy policy is provided for demonstration purposes to show awareness of GDPR requirements.

2. Data We Collect (Demo Context)

In a real production environment, an e-commerce site like ELLORE would collect:

  • —Account data: Name, email address, password (hashed)
  • —Order data: Delivery address, order history, payment method (tokenised — never stored in full)
  • —Usage data: IP address, browser type, pages visited, session duration via CloudWatch logs
  • —Marketing data: Email address for newsletter (opt-in only)

In this demo: Cart data is stored in your browser's localStorage. Contact, newsletter, and checkout forms may submit the data you enter to AWS API endpoints used for this educational project. No real payment is processed on the site.

3. Legal Basis (GDPR Article 6)

Processing of personal data in a real ELLORE deployment would be based on: (a) contract performance for order fulfilment, (b) legitimate interests for fraud prevention and security, (c) consent for marketing communications, and (d) legal obligation for tax and accounting records.

4. AWS Data Storage

This demo site runs on AWS infrastructure. In a real deployment, data would be stored in:

  • —Amazon DynamoDB — demo records such as contact requests, orders, and newsletter subscriptions
  • —Amazon S3 — product images and static assets
  • —Amazon CloudWatch Logs — access logs retained for 30 days
  • —AWS CloudTrail — API audit logs retained for 90 days

All AWS resources used in this project are within the AWS re/Start lab environment and governed by AWS's own privacy and security standards (ISO 27001, SOC 2, GDPR compliant infrastructure).

5. Cookies

This demo site uses localStorage (not cookies) to store your cart contents temporarily in your browser. No tracking cookies, advertising cookies, or analytics cookies are used on this demo site.

A real production deployment would use: session cookies (essential), preference cookies (language), and optionally analytics cookies (with consent) for CloudFront performance monitoring.

6. Language Toggle

The current demo provides an English/German interface using predefined frontend text strings. No paid machine-translation service is enabled in this version of the project, and no user-submitted text is sent for translation.

7. Your Rights (GDPR)

Under the General Data Protection Regulation (GDPR), you have the right to: access your data, rectify inaccurate data, request deletion ("right to be forgotten"), restrict processing, data portability, and to object to processing.

To exercise these rights in a real deployment, contact: privacy@ellore.de. Response time: within 30 days as required by GDPR Article 12.
